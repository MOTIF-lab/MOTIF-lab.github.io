Request access and cite

  1. Read the card. Each project page states the license, what is and is not released, and the privacy measures taken (pseudonymous drivers, blurred faces and plates, skeleton-only cabin data).
  2. Request on Hugging Face with an institutional email and a sentence on the intended use. Gated releases are reviewed by the lab; samples unlock automatically.
  3. Cite the paper that introduced the release — BibTeX is on every project page — and link back to the dataset page in your work.
